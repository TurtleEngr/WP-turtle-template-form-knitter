an email will be sent to website editors and/or a pending post will be

</details>

Your full name*
    [text* your-name autocomplete:name minlength:3 maxlength:60 size:60
    placeholder "First L."]

<details><summary>Your email*...</summary>
We need this if we have questions about the event.
</details>
    [email* your-email autocomplete:email minlength:3 maxlength:60 size:60]

<h2>Details</h2>

<details><summary>Title*...</summary>
Required. The short title part that is before a ":".
</details>
    [text* your-subject minlength:5 maxlength:60 size:40 placeholder "Title"]

<details><summary>Subtitle...</summary>
Optional: The part of the title that is usually after the ":" or on
the line below the title.
</details>
    [text subtitle-1 minlength:5 maxlength:80 size:80 placeholder "Subtitle"]

<details><summary>Author*...</summary>
Required. Primary author for a book or article. If more than one put
the other names in the Authors field. If no author, maybe use the
publication's name?
</details>
    [text* Author-1 minlength:5 maxlength:60 size:60 placeholder "Last, First"]

<details><summary>Authors...</summary>
If more than one author, put the other author names here.
</details>
    [text Author-2 minlength:5 maxlength:80 size:80 placeholder "First Last, ..."]

<details><summary>Publication Date*...</summary>
Publish date of a book or an article. Guess, if you don't know, or put
in the date you saw the article.
</details>
    [date* pub-date-1 minlength:10 maxlength:12 size:12]

<details><summary>Publisher...</summary>
For books this is easy. For articles, the publication name or
publisher.  For videos, the Channel name or the hosting organization
name.
</details>
    [text publisher-1 minlength:5 maxlength:60 size:60 placeholder "Publisher"]

<details><summary>Main URL*...</summary>
If book, the URL for where the book could be bought.
If article, URL for article
If video, URL for video
</details>
    [url* main-url-1 minlength:10 maxlength:400 placeholder "https://Main-URL"]

<details><summary>Suggested Image URL...</summary>
While optional, your post will go up a lot faster if you include an
image. URL for event post's images. Or use the next field to attach an
image.
</details>
    [url image-url-1 minlength:10 maxlength:400 placeholder "https://IMAGE-URL"]

<details><summary>Attach Suggested Image...</summary>
Optional. Attach an image from your PC (jpg, jpeg, png). 5MB limit.
</details>
    [file image-file-1 limit:5mb filetypes:jpg|jpeg|png]

<details><summary>Summary* (5,000ch)...</summary>
Give a brief summary of the book or article.
Also include URL's for, author interviews or talks, author website,
author blog site such as substack.
If you want to post a complete article, contact the webteam.
</details>
    [textarea* summary-1 maxlength:5000 placeholder "Description"]

Use this form to add new posts that would be of interest to ORG.
The web team will receive an email and add the post.
Do not use this for adding events; use the "Add Event Form."

See the Guidelines for Posts page for the kinds of posts we are
interested in.

If you have defined the publish-date, when you look at the generated post, its publish date it might show "immediately" which looks like it didn't get the date from the form. Click on the "immediately" so you can see if the date has been correctly set.

Create contact form: add-event

Form tab

<details><summary>Click here for more details...</summary>
You can click on the lines with an arrow icon to get more details
about a field. Fields with a * are required. When you submit this form
an email will be sent to website editors and/or a pending event post
will be created.
</details>

Your name*
    [text* your-name autocomplete:name minlength:3 maxlength:60
    placeholder "First Last"]

<details><summary>Your email*...</summary>
We need this if we have questions about the event.
</details>
    [email* your-email autocomplete:email minlength:8 maxlength:60]

<details><summary>Is this urgent?...</summary>
If Yes, we will try to get this posted soon (1 to 2 days).
</details>
    [radio urgent-1 default:1 "Normal" "Urgent"]

<details><summary><b>Event URL...</b></summary>
If the event is posted at another site where people can sign up, or
get more information, please include that URL.
</details>
    [url event-url-1 minlength:10 maxlength:400 placeholder "https://EVENT-URL"]

<details><summary>Is this an ORG-Sponsored event or meeting?</summary>
ORG sponsored events will probably be featured on the home page. A
"Yes" means the Council has approved sponsoring this event. You can
use the "Contact Us" form to ask.
</details>
    [radio org-event-1 default:1 "No" "Need-to-Ask" "Yes"]

<h2>Details</h2>

<details><summary>Title*...</summary>
Required.
</details>
    [text* your-subject minlength:5 maxlength:40 placeholder "Title of event"]

<details><summary>Date*...</summary>
Required. The event post will "expire" after this date. However, the
post might be reused later to post photos from the event.
</details>
    [date* date-1 minlength:10 maxlength:20 placeholder "YYYY-MM-DD"]

<details><summary>Begin Time...</summary>
Use 24-hour format. For example, use 14:30 for 2:30pm.
If this is an all day event, say that in the "Notes" textbox.
</details>
    [text time-beg-1 size:5 minlength:5 maxlength:5 placeholder "HH:MM 24-hour format"]

<details><summary>End Time...</summary>
Required, if there is a begin time.
</details>
    [text time-end-1 size:5 minlength:5 maxlength:5 placeholder "HH:MM 24-hour format"]

<details><summary>Is this a repeating event?...</summary>
If Yes, describe the repeating information in the "Notes" textbox.
</details>
    [radio repeating-1 default:1 "No" "Yes"]

<details><summary>Location...</summary>
Required. Give the address or if an online event, give the URL.
</details>
    [text location-1 minlength:5 maxlength:80 placeholder "street, city, or URL"]

<details><summary>Group's URL...</summary>
Optional. The sponsoring group's URL.
</details>
    [url group-url-1 minlength:10 maxlength:400 placeholder "https://GROUP-URL"]

<details><summary>Suggested Image URL...</summary>
Optional. URL for event post's images. Or use the next field to attach
an image.
</details>
    [url image-url-1 minlength:10 maxlength:400 placeholder "https://IMAGE-URL"]

<details><summary>Attach Suggested Image...</summary>
Optional. Attach an image file from your PC (jpg, png). 3MB
limit. Preferred aspect ratio 16:9 or 9:16.
</details>
    [file image-file-1 limit:3mb filetypes:jpg|jpeg|png]

<details><summary>Describe the event* (5,000ch limit)...</summary>
Required. Give details about the event. What is the purpose, group
sponsoring the event, directions, etc. Only include plain text
here--do not cut/paste formatted text.
</details>
    [textarea* event-details-1 maxlength:5000 placeholder "Describe the event"]

<h2><a target="_blank" href="/categories-and-tags/">categories-and-tags list</a></h2>

<details><summary>Categories*...</summary>
Check all that apply. For a complete list of categories, see: <a
target="_blank"
href="/categories-and-tags/#categories">categories-and-tags</a>. Add
the alternative category in the "Notes" textbox.
</details>
    [checkbox* category-1 default:1
 "announcement"
 "podcast"
 "townhall"
 "webinar"
 "Other - see Notes"]

<details><summary>Tags*...</summary>
Check all that apply. For a complete list of tags, see <a
target="_blank"
href="/categories-and-tags/#tags-with-descriptions-and-counts">categories-and-tags</a>. Add
the alternative tags in the "Notes" text box.
</details>
    [checkbox* tags-1 default:1
 "event"
 "meeting"
 "Other - see Notes"]

<details><summary>Notes to editor (1,000ch)...</summary>
Details for the web-team. This will not go in the event's post. For
example, if this is a repeating event, describe that here. Also,
suggest other categories and tags here.
</details>
    [textarea event-notes-1 maxlength:1000]
